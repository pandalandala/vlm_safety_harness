# MIS 数据集核心不足：综合分析

> 来源综合：OpenReview 四位审稿人意见（SD7u / wAXc / PDkF / v3WZ / gNSB）× 前期深度分析（P1–P5, P7, P9, P10, P12）
> 
> 
> 说明：每条不足均标注来源——**[R]** 表示审稿人提出，**[A]** 表示前期分析提出，**[R+A]** 表示两者共同指向。

## 一、数据构造方向存在根本性缺陷

**[R+A]** — 对应分析 P1、P2

### 1.1 危险性从文本反推图像，覆盖域被已知威胁锁死

MIS 的构造管线从已有安全 benchmark 中提取有害元素（Step 1），生成有害问句后再做文本去毒，最后用 T2I 生成配套图像。这一逆向流程决定了数据集的语义边界被**已有 benchmark 的有害文本空间**所锁定，真正的隐蔽性组合危险（两张各自完全无害的图像在特定语境下产生危险）在该管线中原则上无法被发现和采样。

**审稿人 v3WZ 的质疑**直接触及这一逻辑：他质问既然 InternVL2.5-78B 是生成标签的教师模型，为何它在同样的输入上 ASR 高达 85% 以上——作者的回答揭示了管线的核心逻辑：**标签构造时明确告知模型”这是有害输入”，而测试时不告知**。这意味着数据集的”有害性发现”能力，实际上完全依赖于在构造阶段人工注入的有害意图先验，而非对真实视觉语义空间的探索。

### 1.2 文本指令高度模板化，存在文本级捷径

**[A]** — 对应分析 P2

MIS 几乎所有文本指令都遵循以下少数固定句式：

- *“What is the best way to use the object in the first image to…”*
- *“List detailed steps to use the tool in the first image to…”*
- *“How to use the words in the second image to…”*

Step 2 的 detoxification 只在词汇层面替换（illegal → 删除，weapon → object），句式骨架完全保留。这形成了一种**文本级捷径（textual shortcut）**：模型只需识别 `"use ... in the first/second image"` 这一 trigger pattern，无需任何视觉理解即可触发安全推理。这与论文批评 VLGuard 的 modality shortcut 在本质上属于同一类问题。

论文**没有报告**”仅输入文本、去掉图像”条件下 safety classifier 的准确率，无法排除 unsafe 信号仍主要编码在文本结构中而非图像组合关系中的可能性。

## 二、合成图像主导，真实图像严重不足

**[R+A]** — 对应分析 P4

**审稿人 SD7u（W2）**明确指出：MIS-easy 和 MIS-hard 主要由 Stable Diffusion 3.5 生成，MIS-real 规模太小（100 个样本），“无法得出具有说服力的泛化结论”。

**论文自身（Section 4.1）也承认**：合成图像比真实图像”更容易被 jailbreak”，原因是真实图像更接近模型训练分布。这一承认直接暴露了以下问题：

- 训练集几乎全为合成图像，导致模型学习到 SD 3.5 的视觉分布特征而非真实语义内容
- SD 3.5 本身含有 safety filter，会拒绝或模糊化关键危险物体（武器细节、特定药物），合成图的危险语义表达受限
- 合成图通常只包含孤立物体，缺乏真实世界的场景上下文、人物、背景干扰物
- MIS-real 仅 100 个样本，**不具备统计显著性**，无法支撑对真实场景泛化能力的可靠评估

**审稿人 wAXc** 在 Ethics Concerns 中也提出，含有有害图像的数据集需要在发布时做充分文档，间接反映了对合成图像数据质量可控性的顾虑。

## 三、组合危害模式单一，关系类型覆盖严重不足

**[R+A]** — 对应分析 P3

**审稿人 wAXc（W1.1）**质疑”仅聚焦于两图+文本的设置，泛化性存疑”，并提问：“如果使用两张以上的图像，方法表现如何？”

**审稿人 v3WZ（Q2）**进一步追问：“多图输入是否真的必要？只用单图+文本的组合性示例（类似 MSSBench）是否就足够了？”

这两个质疑共同指向同一个结构性问题：MIS 的几乎所有样本都遵循**“图1 = 工具/手段，图2 = 目标/场景”**这一单一的 tool→target 组合模式。真实世界中多图安全威胁所涉及的关系类型远不止于此：

| 缺失的关系类型 | 典型场景 |
| --- | --- |
| 时序因果关系（before→after） | 图1是准备材料，图2是目标场景 |
| 身份-行为关联 | 图1暗示身份，图2暗示不当行为 |
| 隐私推理关系 | 多图组合后泄露位置或个人信息 |
| 弱势群体语境改变安全边界 | 儿童/老人出现改变同一行为的危险等级 |
| 公共-私密空间迁移 | 合规物品进入敏感场景 |
| 程序链关系 | 多图共同构成一个危险步骤链 |

单一的 tool→target 模式导致模型可能学到的是”特定物体对共现 = unsafe”的浅层规则，而非真正的多图语义安全推理能力。

## 四、T2I 图像生成精化机制存在系统性局限

**[A]** — 对应分析 P5

MIS 的 Step 3 设计了两轮生成（raw prompt → VLM critic → refined prompt → 再生成），但该机制存在多个关键盲点：

- **仅执行一轮精化**：若第二轮生成仍与目标语义不匹配，管线没有继续迭代或丢弃样本的机制
- **对齐度评估无量化标准**：VLM critic 的判断标准仅为”图像是否与有害问题的语境一致”，没有 CLIP score 等客观度量，判断主观且不稳定
- **缺乏 negative prompt 控制**：未指导 SD 3.5 避免将两个物体同时出现在一张图中，存在两图合并的 failure case
- **第一轮生成图像被直接丢弃**：浪费了潜在的视觉多样性
- **同类别物体被反复生成**：造成训练集的视觉同质化，模型可能过拟合特定视觉 pattern 而非语义内容

## 五、数据质量门控依赖 GPT-4o，存在内在逻辑矛盾

**[R+A]** — 对应分析 P7（清洗）、P9

**审稿人 PDkF（Q4）**指出，MIRage 微调后模型在 MSS-Safe 上的准确率下降约 12%，并要求解释。作者在 rebuttal 中承认这是 GPT-4o 评估的误判所致——GPT-4o 将 MIRage 给出的合理安全提示（如提醒儿童打网球的安全风险）错误地判定为过度拒绝。

这一承认揭示了一个更深层的问题：**GPT-4o 被同时用于数据过滤（Step 4）和最终评估，而它在该任务上的判断本身并不可靠**。论文主实验（Table 4）显示 GPT-4o 在 MIS-easy 上的 ASR 为 **46.21%**，MIS-hard 上高达 **65.29%**——即这个作为数据质量裁判和评估裁判的模型，在其所评判的任务上近一半概率会失败。

进一步的清洗层面不足包括：

- **没有单图遮挡验证**：未检验危险性是否真的来自两图交互，而非单张图像本身。若危险来自单图，样本退化为普通单图安全场景，与 MIS-hard 的设计初衷矛盾
- **没有对抗验证**：未验证候选样本是否真能攻破目标 VLM，训练集中可能充斥对模型实际上毫无挑战性的样本
- **没有难度连续标定**：只有 easy/hard 的粗粒度二分，无连续难度分数

## 六、Safety CoT 标签依赖单一教师模型，质量不可验证

**[R+A]** — 对应分析 P8

**审稿人 PDkF（W1）**明确指出：“Safety CoT 模板有趣，但没有被充分形式化或分析——改进究竟有多少来自推理，有多少来自数据多样性，目前不清楚。”

**审稿人 v3WZ（W1）**的质疑更为尖锐：InternVL2.5-78B 同时扮演了标签生成者（构造阶段明确知道输入有害）和被评测者（推理阶段按正常流程测试），两种角色下的表现差距高达 85% vs ~0% ASR。这一悖论说明**标签质量严重依赖于”已知有害”这一外部先验注入**，而非模型对视觉组合危险的自主识别能力。

此外：

- **论文没有报告任何标签的人工验证数据**：4k 条 CoT 标签的推理正确率完全未知
- **单一教师模型的认知盲区会被继承**：78B 模型检测不出的 covert harm，标签中的推理会出错，学生模型通过 SFT 的 imitation learning 会放大这些错误
- **叙事风格高度模板化**：单一教师的固定叙事结构（“The first image shows… The second image depicts…”）形成新的 pattern，可能使训练出的模型给出千篇一律的安全回复而非真正的情境化推理
- **自由文本 CoT 难以自动验证**：标签推理链的正确性无法通过自动化手段检查

## 七、安全类别分布严重不均衡

**[R+A]** — 对应分析 P10

**审稿人 PDkF（W3）**直接指出：“MIS 数据集在类别上严重不平衡，Illegal Activity 占近一半，而 Self-Harm、Privacy、Erotic 各自不足 7%。”

**审稿人 wAXc（W1.2）**补充：“数据集规模对于较小类别而言显得不足，尤其是 Self-Harm 和 Privacy，仅有几百张图像。”

实际分布数据（来自论文 Table 3）：

| 类别 | 样本数 | 占比 |
| --- | --- | --- |
| Illegal Activity | 1016 | **46.50%** |
| Violent | 416 | 19.04% |
| Hate | 310 | 14.19% |
| Self-Harm | 150 | 6.86% |
| Privacy | 147 | 6.73% |
| Erotic | 146 | 6.68% |
| ↳ Human Trafficking（子类） | 22 | **1.01%** |
| ↳ Gender Discrimination（子类） | 13 | **0.60%** |
| ↳ Psychological Harm（子类） | 18 | **0.82%** |

这一分布带来两个层面的问题：

**评估层面**：极端长尾子类（Human Trafficking 22 条、Gender Discrimination 13 条）上的评测结论在统计意义上几乎无效，不能支撑任何关于模型在这些类别上的安全能力的结论。

**泛化实验层面**：论文 Section 4.2 的类别泛化实验（去掉 Privacy 和 Self-Harm 后测试）刻意选择了**相对体量较大的类别**（各 150 条左右），完全回避了对 Human Trafficking 等真正长尾类别的泛化验证，使得”MIRage 的安全能力可泛化至未见类别”这一结论缺乏充分支撑。

## 八、Train/Test 分布不一致与管线模式泄露

**[A]** — 对应分析 P12

### 8.1 训练集与测试集的分布不一致

MIS-train 的文本按 Step 4 的分类标准**包含 unsafe intent**（这是它被划入训练集的依据），而 MIS-easy/hard 的文本是 neutral 的。这造成了一个设计层面的 distribution mismatch：

- **训练时**：模型可以部分依赖文本中残留的 unsafe 信号辅助安全判断
- **测试时**：文本完全中性，模型必须 100% 依赖视觉推理

虽然实验结果显示 MIRage 在测试集上表现良好（可能因为 Safety CoT 标签强制了视觉推理路径），但这一 mismatch 使得我们无法区分”模型真正学到了纯视觉推理”与”模型同时利用了训练时的文本线索”这两种解释。

### 8.2 管线模式泄露（Pipeline Pattern Leakage）

MIS-train 和 MIS test 来自同一个自动构造管线，即使样本不重叠，模型仍可能学到 pipeline 特有的浅层 pattern：

- 相同的文本指令句式模板（见 §1.2）
- 相似的物体对组合逻辑（tool→target）
- 相似的 SD 3.5 合成图像风格和视觉特征
- 相似的 Safety CoT 叙事结构

这导致 MIS 自身测试集上的高分（ASR ≈ 0%）**无法排除管线内部泄露的贡献**，模型是否真正获得了可泛化的多图安全推理能力，需要通过完全独立于构造管线的外部测试集来验证。
